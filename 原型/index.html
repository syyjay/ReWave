HIGH-FIDELITY PROTOTYPE · v2.0

ReWave 高保真原型

移动端「音频编辑 + 格式转换」双引擎工具的原型总览。深色主题、品牌渐变（#4F6BFF → #7C3AED）、Inter + JetBrains Mono 字体，全部界面按 iPhone 15 Pro（393×852 · Dynamic Island）绘制，可直接作为开发交付依据。

20 个界面 · iPhone 15 Pro 393×852 深色主题 · 品牌 Token 全量落地 HTML + Tailwind + FontAwesome 波形为脚本程序化生成

用户与核心诉求

五类目标用户（播客主播 / 短视频博主 / 音乐爱好者 / 办公人士 / 普通用户），核心诉求收敛为三条：快速处理（剪辑、降噪一步到位）、批量提效（一次 100+ 文件）、体积可控（压缩 + 格式转换）。高频路径：录音 → 编辑 → 导出；视频 → 提取 → 转换。

信息架构与交互逻辑

4 Tab 结构：首页聚合快捷入口与最近记录，编辑承载波形工作台与 AI 工具，转换以 9 宫格工具覆盖全场景，设置管理订阅与偏好。所有子页面均为「选择文件 → 配置参数 → 预估反馈 → 执行」统一心智，降低学习成本。

关键设计决策

处理类页面一律提供体积/耗时预估（如 342MB → 12MB 对比条）建立信任感；PRO 能力前置展示、点击解锁（订阅引导页统一承接）；危险操作（删除源文件）默认关闭；批量任务支持后台运行并可随时查看逐文件进度。

01

新手引导与首页

onboarding → home

首次启动用 3 页讲清三大卖点（编辑 / 转换 / 智能处理），随后进入首页。首页是效率中枢：6 宫格快捷工具直达高频功能，最近编辑与最近转换让用户一键回到上次任务。

02

录音与编辑工作台

recorder → editor → ai-tools

核心生产力链路：录音界面提供实时波形、电平表与削波警告；编辑工作台支持多轨（最多 4 轨）、选区、时间标尺与完整工具栏；AI 工具以底部面板形态叠加出现，不打断编辑上下文。

03

转换中心与工具集

converter → 各子工具

9 宫格覆盖格式转换、批量、压缩、合并、分割、视频提取、铃声、元数据与文件信息。所有工具页遵循统一模式：源文件卡片 → 参数配置 → 体积/耗时预估 → 主 CTA。

04

导出、订阅与设置

export → paywall · settings

导出页集中所有输出选项（命名 / 格式 / 质量参数 / 预估大小）；订阅引导页用功能对比 + 三档方案（¥18/¥128/¥298）+ 免费试用 CTA 承接全部 PRO 入口。设置页采用「入口收敛」：主页仅保留高频项（约 10 行一屏），录音/导出默认参数收纳到二级页。

05

扩展工具

metadata · file-info · ringtone · video-extract

面向细分场景的补充工具：元数据编辑（封面 + ID3 字段）、文件信息（技术参数 + 响度分析报告）、铃声制作（40 秒限制 + 淡入淡出）、视频提取音频（真实缩略图 + 音轨检测）。
