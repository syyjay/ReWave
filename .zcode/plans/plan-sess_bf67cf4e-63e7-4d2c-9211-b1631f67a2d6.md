# ThemeKit 主题库封装计划

## 目标
把 `项目文档.md` 中的 ReWave 设计系统封装为可复用的 SwiftUI 主题库（本地 SPM 包），支持多主题注册、每主题浅色/深色双外观、含颜色与字体 Token，iOS 15+ 可用，主题切换与暗黑切换同样即时无感。

## 架构决策
| 决策 | 选择 | 理由 |
|---|---|---|
| 库形式 | 本地 SPM 包 `Packages/ThemeKit` | 整文件夹可直接拷给其他 app 复用；库零资源依赖 |
| 切换机制 | 根视图把「主题 × colorScheme」解析后注入 `\.theme` 环境值 | 与系统暗黑同一传播机制，全部视图原子更新（满足"无感切换"） |
| 状态管理 | `ObservableObject` + `@EnvironmentObject`（非 @Observable） | @Observable 需 iOS 17，目标 15.6 |
| 字体 | 库存字体名 + 运行时探测缺失自动回退 SF 字体；Inter/JetBrains Mono 字体文件放 app | 库无资源耦合；其他 app 可带自己的字体 |
| 持久化 | UserDefaults 存主题 id + 外观偏好 | 设置页「浅色/深色/跟随系统」直接消费 |

## 新增文件

### 1. `Packages/ThemeKit/`（本地 Swift Package，tools 5.9，platforms: [.iOS(.v15)]）
- **`Theme.swift`** — `protocol Theme { id, displayName, light/dark: ThemeAppearance, typography }` + `appearance(for:)` 扩展；`struct ThemeAppearance { palette, effects }`
- **`ThemePalette.swift`** — 按文档 2.2–2.7 分组的语义色（Primary 阶梯/Background/Surface/Border/Text/Semantic 含背景版/Icon 单色），全嵌套 struct + `let`，公开 init
- **`ThemeEffects.swift`** — 品牌渐变（135° LinearGradient）+ 5 档阴影 `ThemeShadow{color,radius,x,y}`（浅色下阴影不同，故归入 Appearance）
- **`ThemeTypography.swift`** — 文档 4.2 全部字号 Token（display/heading1-3/body 系/caption/tiny/micro/sectionLabel/mono 系）；`Font.themed(family:size:weight:)` 工厂：UIFontDescriptor 按家族+字重解析，家族缺失回退 `.system`；附 `.sectionLabelStyle()` 修饰符（11px/600/大写/1.5 字距）
- **`ThemeMetrics.swift`** — 全局静态 Token：圆角（6/10/14/18/24/full）+ 间距（4–48），不随主题变
- **`ThemeManager.swift`** — `@MainActor ObservableObject`：注册主题数组、当前主题、`AppearancePreference{system,light,dark}`、UserDefaults 持久化、派生 `preferredColorScheme`
- **`ThemeEnvironment.swift`** — `\.theme` EnvironmentKey（默认 ReWave 深色）+ `.themeManaged()` 根修饰符：读取 colorScheme → 解析出 `ActiveTheme{id,colors,effects,typography}` 注入环境
- **`Color+Hex.swift`** — 文档 3.2 的 `Color(hex:)`
- **`BuiltIn/ReWaveTheme.swift`** — 深色=文档原值；浅色=推导值（见下表）

### 2. ReWave 浅色推导值（深色默认，浅色备用）
| 组 | 浅色取值 | 说明 |
|---|---|---|
| Background | base `#F5F6FA` / elevated `#FFFFFF` / elevated2 `#FFFFFF` | 近白微蓝底，层级靠边框+阴影 |
| Surface / Border | 白色透明度 → 黑色透明度（0.03/0.06/0.08/0.12 与 0.05/0.08/0.14） | 与深色对称反转 |
| Text | primary `#0A0A0F`，secondary 黑72%，tertiary 黑55%，quaternary 黑40%，disabled 黑25%，onBrand 白 | 三/四级比深色略加深以保证浅底 AA 对比度 |
| Semantic | `#059669 / #D97706 / #DC2626 / #0891B2`，背景 10% | 各加深一档保证浅底对比 |
| 阴影 | 黑 6%/8%/12% 三档 + 品牌光晕 20%/28% | 比深色更轻 |
品牌色阶梯、渐变、Icon 规范两种外观一致。

### 3. App 侧（利用文件系统同步组，新增文件免改 pbxproj 源文件引用）
- **`ReWave/Theme/EmberTheme.swift`** — 第二个示例主题（暖橙渐变 `#FF7A45→#E0483E` + 暖调中性底），约 60 行，证明"其他 app 一个文件定义自己的主题"
- **`ReWave/ContentView.swift` 重写** — 主题展示 Demo：外观选择（跟随系统/浅色/深色）、主题切换（ReWave↔Ember）、全 Token 色卡网格、字体样例、渐变/阴影/卡片示例（body ≤40 行拆子视图）
- **`ReWave/ReWaveApp.swift`** — `@StateObject ThemeManager`（注册两主题，默认 ReWave）+ `.themeManaged()` + `.environmentObject`
- **字体资源** — 从 rsms/inter 与 JetBrains/JetBrainsMono 的 GitHub Release 下载静态字重（Inter 400/500/600/700/800、JBMono 400/500/700，均 OFL 开源）放 `ReWave/Resources/Fonts/`；新建 `ReWave/Info.plist` 仅含 `UIAppFonts`，pbxproj 设 `INFOPLIST_FILE`（GENERATE_INFOPLIST_FILE 保持 YES 合并生成）

### 4. pbxproj 手工接线（新格式 objectVersion 77）
新增 `XCLocalSwiftPackageReference`（Packages/ThemeKit）→ PBXProject `packageReferences`；新增 `XCSwiftPackageProductDependency`（ThemeKit）+ 对应 `PBXBuildFile` → target `packageProductDependencies` + Frameworks phase。

## 验证
1. `xcodebuild -project ReWave.xcodeproj -scheme ReWave -destination 'generic/platform=iOS Simulator' build` 零错误
2. 模拟器安装运行 + 截图：验证浅/深、双主题即时切换（满足全部 6 条需求）

## 范围外（本次不做）
UI 组件库（按钮/卡片封装，后续可基于 Token 做）、Dynamic Type 缩放（按文档固定字号）、主题切换动画（即时切换=暗黑同等效果）

## 遵循 CodeStyle
MVVM 模块边界（app 不碰库内部类型，仅通过 `Theme` 协议扩展）；全部完整可编译代码、`///` 公开注释、无 force unwrap/AnyView/占位符；iOS 15 兼容注记。
